# Gold Price Scraper – Bajus

A simple Python project that scrapes the **current gold price from the Bajus website** and displays or stores it for further use. This project is intended for **learning and educational purposes**.

---

## 📌 Project Overview

This script:
- Fetches gold price data from the Bajus website
- Extracts relevant gold rate information using web scraping
- Displays the gold price in a readable format

---

## 🛠️ Technologies Used

- Python 3

---

## ⚙️ Installation

1. Clone the repository or download the project files
2. Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ How to Run

```bash
python app.py
```

The script will fetch and display the latest gold price from the Bajus website.

---

## 📄 Example Output

```
Gold Price (Today): XXXX per gram
```
